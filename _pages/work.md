## 华为技术有限公司 华为云计算公司 资源运营数字化使能团队 (2025.07 至今)

## 华为技术有限公司 · 华为云计算公司
**资源运营数字化使能团队｜2025.07 – 至今**

围绕云资源运营数字化建设，开展业务数据分析、数据处理与建模、业务系统开发及 AI Agent 应用建设。结合资源运营场景，将业务规则、数据能力和运营流程转化为可复用的软件工具与智能化应用，推动传统运营流程向自动化、标准化和智能化方向演进。

**主要工作内容：**

**1. 数据分析与数据工程**
- 基于 SQL 开展多源业务数据查询、清洗、关联及聚合分析，支撑云资源供需分析、资源可售性分析及运营决策。
- 基于 ClickHouse、PostgreSQL、MySQL 等数据库开展业务数据查询与处理，梳理业务实体、数据关联关系及核心指标口径。
- 参与业务数据建模与数据加工，推动分散业务数据向结构化、标准化和可分析的数据资产转化。

**2. 业务系统与数据产品开发**
- 面向云资源运营场景开展业务需求分析，将复杂业务规则、运营流程转化为系统功能和自动化处理逻辑。
- 基于 Java、Spring Boot 等技术参与后端业务开发，涉及业务逻辑实现、API 接口设计及内部系统集成。
- 参与运营工具与数据应用建设，将数据查询、计算分析和业务处理能力融入运营流程，提升业务处理效率。

**3. AI Agent 与智能化应用开发**
- 面向云资源运营业务场景开展 AI Agent 应用开发，探索大语言模型在数据查询、业务分析及运营操作中的应用。
- 基于 Agent Skills 机制，将业务知识、业务规则、数据查询及操作流程封装为可复用的业务能力，构建面向运营场景的 Skill 体系。
- 基于 MCP（Model Context Protocol）开发和集成业务工具，打通 Agent 与内部业务系统、数据服务及 API 接口之间的调用链路。
- 结合 Python 开发业务自动化工具，将复杂业务规则和计算逻辑程序化，实现传统人工处理流程的自动化。
- 推动 Agent 应用配套基础设施及内部工具集成建设，促进业务能力标准化、模块化和复用。

**核心技术栈：**

Python、Java、Spring Boot、SQL、ClickHouse、PostgreSQL、MySQL、Agent Skills、MCP、LLM、API Integration。
